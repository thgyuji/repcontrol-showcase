# Assets do RepControl Showcase

Nesta pasta ficam os arquivos de mídia visual (prints de tela, diagramas e animações em GIF) que ilustram o funcionamento do sistema no `README.md`.

## Arquivos Recomendados

| Arquivo | Descrição | Formato Recomendado |
|---|---|---|
| `demo_menu.png` | Print do menu administrativo enxuto com 6 botões no Telegram. | PNG / WebP |
| `demo_signup.gif` | Gravação rápida do autocadastro do morador (apenas nome) em segundos. | GIF / MP4 / WebP |
| `demo_receipt.gif` | Gravação do envio do print de comprovante com revisão e data atual. | GIF / MP4 / WebP |
| `demo_sheet.png` | Print da planilha Google com abas padronizadas, Chips Inteligentes e Dashboard. | PNG / WebP |
| `architecture.png` | (Opcional) Diagrama visual exportado do Excalidraw ou Figma caso não utilize o Mermaid. | PNG / SVG |

> [!TIP]
> Ao gravar GIFs ou tirar prints do bot ou da planilha, lembre-se de borrar ou ocultar dados pessoais reais (como telefones, chaves Pix e IDs bancários) usando ferramentas simples como CleanShot X, ShareX, GIMP ou a ferramenta de recorte do sistema.
